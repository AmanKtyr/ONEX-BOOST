Outbound SMTP Gateway Setup Guide

Follow our step-by-step instructions to configure reliable email delivery for ONEX BOOST.

Setting Up Gmail / Google Workspace (SMTP)
Crucial Requirement: Google blocks standard account passwords for SMTP. You MUST enable 2-Step Verification and generate a dedicated 16-character App Password.
  1. Enable 2-Step Verification: Go to your Google Account Security Settings ↗ and ensure 2-Step Verification is switched ON.
  2. Generate an App Password: Direct link to Google App Passwords ↗. (Or search "App passwords" in the top Google search bar).
  3. Create Password: Name your app (e.g. ONEX BOOSTGym Platform) and click Create.
  4. Copy 16-Character Password: Google displays a 16-letter code in a yellow box (e.g. abcd efgh ijkl mnop). Copy it without spaces.
  5. Configure in ONEX BOOST:
    FieldRequired Value
    SMTP Hostsmtp.gmail.com
    Port587
    SMTP UsernameYour full Gmail address (e.g. ONEX BOOSTgym@gmail.com)
    SMTP PasswordYour 16-character Google App Password
    Sender 'From' EmailSame as your Gmail address
    EncryptionCheck Enable TLS (Port 587)
Setting Up Brevo / Sendinblue (Recommended Free Tier)
Why Brevo? Brevo offers 300 free emails per day forever with near-zero spam flagging and doesn't require complex 2FA app passwords.
  1. Create Account: Sign up at Brevo.com ↗ (Free plan).
  2. Find SMTP Credentials: In Brevo dashboard, click your account name at top-right → select SMTP & API → open the SMTP tab.
  3. Generate SMTP Key: Click Generate a new SMTP key, name it ONEX BOOSTGym, and copy your master key.
  4. Verify Sender: Go to Senders, Domains & Dedicated IPs in Brevo to verify the email address you will send from.
  5. Configure in ONEX BOOST:
    FieldRequired Value
    SMTP Hostsmtp-relay.brevo.com
    Port587
    SMTP UsernameYour Brevo login email address
    SMTP PasswordYour Brevo SMTP Key (starts with xsmtpsib-...)
    Sender 'From' EmailYour verified sender address in Brevo
    EncryptionCheck Enable TLS (Port 587)
Setting Up Twilio SendGrid
  1. Sender Authentication: Sign in at SendGrid Dashboard ↗ and complete Sender Authentication (Single Sender or Domain).
  2. Generate API Key: Navigate to Settings → API Keys → click Create API Key.
  3. Set Permissions: Name it ONEX BOOST SMTP, select Full Access (or Restricted: Mail Send), and click Create & View. Copy the key (starts with SG.).
  4. Configure in ONEX BOOST:
    FieldRequired Value
    SMTP Hostsmtp.sendgrid.net
    Port587
    SMTP Usernameapikey (Exact literal string)
    SMTP PasswordYour SendGrid API Key (SG.xxxx...)
    Sender 'From' EmailYour verified Single Sender or Domain address
    EncryptionCheck Enable TLS (Port 587)
Setting Up Custom Domain / cPanel / Hostinger Webmail
  1. Access Hosting Webmail: In cPanel, Plesk, Hostinger, or Namecheap, go to Email Accounts → click Connect Devices or Mail Client Manual Settings.
  2. Outgoing Server Details: Notice your Outgoing Server name (often mail.yourdomain.com or smtp.hostinger.com).
  3. Configure in ONEX BOOST:
    FieldSSL Option (Port 465)TLS Option (Port 587)
    SMTP Hostmail.yourdomain.commail.yourdomain.com
    Port465587
    EncryptionCheck Enable SSL (Port 465)Check Enable TLS (Port 587)
    SMTP UsernameYour complete email address (e.g. info@ONEX BOOST.com)
    SMTP PasswordYour mailbox password
    Sender 'From' EmailSame mailbox email address
Common SMTP Issues & How to Fix Them
535 Authentication Failed:

For Gmail, you entered your normal Google password instead of a 16-character App Password, or entered an invalid SendGrid API Key.

Connection Timed Out:

Many hosting providers block port 25 or port 465. Switch to Port 587 with TLS enabled to bypass outbound firewalls.

Sender Address Rejected:

Ensure the Sender 'From' Email Address matches your authenticated email or authorized domain in Brevo/SendGrid/Gmail.

Instant Verification:

Click the "Send Test Email" button on the settings card to dispatch a live verification email to your inbox.
